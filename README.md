# Фокус - задачи

Личный таск-менеджер по методологии GTD. Offline-first PWA: все данные лежат в браузере (IndexedDB), сервер не нужен.

Живая версия: https://s11158.github.io/fokus/

## Что внутри
- Инбокс, «Сегодня-, планировщик, проекты, канбан, календарь, привычки, поиск, умные фильтры
- Быстрый захват задач, таймер фокуса, повторяющиеся задачи, напоминания
- Богатый редактор заметок, drag-and-drop, корзина
- Установка как приложение (PWA), работа офлайн

## Разработка
```
npm install
npm run dev
npm run build
```

## Телеграм-бот захвата (папка bot)
Необязательный локальный мост: пересылает в приложение задачи из Telegram, включая голосовые. Настройка - в `bot/README.md`, секреты в `bot/.env` (не коммитятся).
