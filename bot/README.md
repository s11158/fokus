# Telegram-бот захвата «Фокус»

Принимает сообщения в Telegram (текст и голос), разбирает их через AI и кладёт
задачи в Inbox приложения «Фокус» через локальный HTTP-мост.

## Архитектура

1. Telegram передаёт сообщение боту (index.js).
2. Бот отдаёт текст на AI-разбор (ai.js) и кладёт задачу в очередь (store.js).
3. Приложение «Фокус» опрашивает мост (bridge.js, порт 8787) по /captures и забирает задачи в Inbox.
4. Приложение отправляет в мост снимок списков по /snapshot, откуда бот отвечает на /inbox и /today.

Бот и приложение НЕ имеют общей БД (приложение - offline-first в браузере),
поэтому связь идёт через локальный мост: приложение опрашивает `/captures`
и импортирует их в Inbox, а в `/snapshot` отдаёт списки «Входящие»/«Сегодня»,
чтобы бот отвечал на `/inbox` и `/today`.

## Запуск

```bash
cd bot
npm install
cp .env.example .env   # заполнить TELEGRAM_BOT_TOKEN и ANTHROPIC_API_KEY
npm start              # запускает бота + мост на :8787
```

В приложении: Настройки, далее «Telegram-захват», далее включить, указать адрес моста
(по умолчанию `http://localhost:8787`).

## Команды бота
- любой текст - создать задачу (с AI-разбором)
- голосовое - распознать (STT) и создать задачу
- `/inbox` - показать «Входящие» (из снимка приложения)
- `/today` - показать «Сегодня»

## Без AI / без STT
- Нет `ANTHROPIC_API_KEY` - текст кладётся как заголовок задачи (без разбора).
- Нет `STT_*` - голосовые не распознаются (придёт сообщение об ошибке).

## Только мост (для теста без Telegram)
```bash
npm run bridge        # поднимает HTTP-мост без бота
```

Все токены и ключи - только в `.env` (в коде не хардкодятся).
